什么是真实的

画面里的机械臂末端轨迹、每段动作的时长、蘸取的颜料类型，都来自 GPT-6 Astra 的公开评测记录：AgentArk Task 107 · RobotPainting，金门大桥参考图任务，seed 107，Codex SDK 接入，推理强度 ultra，2026-10-19。三轮分别有 39 / 31 / 33 个动作，共 103 个。

每轮结束时的画布，直接使用记录中保存的 PNG，没有重绘或美化。三轮画布的 SHA-256 已写入页面数据。

什么是重建的

浏览器里没有 Unity、物理引擎或原始任务资产。Panda 机械臂、桌面、颜料盘、光照和笔触铺设都是 Three.js 中的近似重建；动作位置只取末端轨迹，不等价于原始关节控制。

为了让过程看起来接近真实落笔，页面把每一轮的最终画布按“当前笔触颜色”分色，再沿真实轨迹逐笔显露。这只是呈现方式，不代表原始渲染器逐帧的中间画布。落笔宽度由记录的动作高度估计，并非真实笔刷物理。
